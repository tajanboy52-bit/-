# 💎 台炅 우량주 반등 — TK Bluechip (B0.1)

Scout(8082 · 스윙 가상매매) · Danta(8083 · 단타)와 별개인 세 번째 프로그램. **가상 매매 전용 — 주문 기능 없음.**

## 실행
- `Bluechip_Run.bat` 더블클릭 → http://localhost:8084 · 검은 창을 닫으면 서버가 꺼짐
- 데이터: `%APPDATA%\TKBluechip` (bluechip.db · bluechip_config.json · bluechip_server.log)
- 일봉: Scout의 `%APPDATA%\StockScout\scout.db`를 **읽기 전용**으로 사용 → Scout가 켜져 있어 장 마감 동기화(15:50)가 돼야 함
- 처음 실행 때 `seed\` 폴더의 KRX 월별 자료(2019-01 ~ 2026-09 구성 종목 · 업종 · 재무)를 넣음

## 하루 흐름 (평일)
16:40 이후 Scout 일봉에 오늘 날짜가 들어오면 ① 어제 신호 → 오늘 시가 가상 체결 ② +5% 익절 · 40일 만료 판단 ③ 계좌 평가 ④ 오늘 종가로 새 신호(내일 시가 매수 예약) ⑤ 텔레그램 요약.
켜져 있지 않던 날은 다음에 켤 때 차례로 처리.

## 우량주 100
매월 첫 거래일 코스피200 · 코스닥150 구성 종목 중 편입 1년 이상 · 흑자 · 배당 → 60일 변동성 낮은 100개.
10월부터 매월 KRX에서 새로 받으므로 **⚙️ 설정에 KRX 계정 저장 필요** (Scout에 넣은 것과 같음). 없거나 실패하면 지난달 목록을 그대로 씀.
