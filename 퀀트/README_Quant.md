## 한눈에
1,000만 원 모의계좌를 칸 4개로 나눠, 전종목(상장폐지 포함) 검증을 통과한 규칙만 자동으로 매매합니다.

| 칸 | 비중 | 한 줄 규칙 |
|---|---|---|
| 🏔 저변동고점 | 40% | 조용히 52주 고점 근처를 지키는 종목 상위 3 → 20거래일 보유 |
| 🔄 반전·수급 | 25% | 과매도 + 외국인 매수 + 연기금 역방향 상위 3 → 9일 EMA 복귀 · 10일에 매도 |
| 🏛 배당·가치 | 20% | 코스피200 · 코스닥150 중 배당 높고 PBR 낮은 15종목 · 월 교체 |
| 🌙 밤사이 ETF | 15% | KODEX 코스닥150 종가 매수 → 다음날 시가 매도 |

## 처음 설정
1. **Scout(스윙 앱)가 설치돼 있고 매일 켜져 있어야 합니다.** 이 앱은 Scout가 모으는 전종목 일봉 · 외국인/연기금 수급을 읽기 전용으로 씁니다 (`%APPDATA%\StockScout\scout.db`)
   - 백테스트에 실제 ETF 가격을 쓰려면 Scout 폴더의 `ETF_수집.bat`을 한 번 실행해 두세요 (없으면 Scout 일봉에서 찾음)
2. `Quant_Run.bat` 더블클릭 → http://localhost:8085
3. ⚙️ 설정 · 로그 탭
   - **KIS 모의투자 앱키 · 시크릿 · 계좌(8-2)** — 이 앱 전용 모의계좌를 권장합니다 (다른 프로그램이 같은 계좌를 쓰면 '모르는 보유 종목'으로 새 매수가 막힘)
   - HTS ID (선택: 실시간 체결 통보) · KRX 계정 (매월 배당·가치 자료) · 텔레그램 (선택)
   - 🔌 KIS 연결 테스트
4. **🧪 백테스트 탭 → 실행** (몇 분). 설계서 5장 판정을 확인하고, 결과 파일(`%APPDATA%\TKQuant\backtest_result.md`)을 Claude에게 보내 점검합니다
5. ⚙️ **자동주문 켜기** → 다음 날 08:35부터 주문이 나갑니다
6. `Quant_AutoStart_On.bat` — PC가 재부팅돼도 자동으로 켜짐 (Scout 자동 실행도 같이 등록해 두세요)
