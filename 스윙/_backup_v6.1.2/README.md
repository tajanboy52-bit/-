## 설정·데이터 저장 위치

설정과 DB는 프로그램 폴더가 아니라 아래 고정 위치에 저장됩니다.

```
C:\Users\<사용자>\AppData\Roaming\StockScout\
  scout_config.json       설정 (앱키·계좌·텔레그램 등)
  scout_config.json.bak   설정 백업 (본 파일 손상 시 자동 복구)
  scout.db                일봉·추천·보유 기록
```

- 프로그램 파일을 **어느 폴더에 두든, 몇 번을 교체하든** 설정과 데이터가 유지됩니다
- 예전 버전이 프로그램 폴더(또는 다운로드·바탕화면·문서 폴더)에 남긴 설정·DB는 처음 실행할 때 자동으로 가져옵니다
- 설정 화면의 비밀번호 칸이 비어 있어도 "저장됨 ●●●●1234"로 표시되면 저장돼 있는 것입니다. 바꿀 때만 입력하세요
- PC를 옮길 때는 이 `StockScout` 폴더를 통째로 복사하면 됩니다

## 최초 1회 준비

1. **데이터 · 설정** 탭에서 KIS 앱키 입력 후 저장
   - 자동매매(8080)와 **다른 앱키**를 쓰면 토큰 충돌이 없습니다
2. **전체 구축** 버튼 → 40분~1시간
   - ① 전종목(약 2,800) 일봉 1년치 → 거래대금 기준으로 후보풀(약 900) 선정
   - ② 후보풀만 3년치(750일)로 확장 → 백테스트·장기 패턴용
3. 후보풀 자동 확정 → 수급 수집
4. **스윙 추천** 탭에서 **지금 스캔**

이후에는 증분 동기화로 3~5분이면 갱신됩니다.

## 자동 스케줄 (v1.4)

서버만 켜두면 전부 자동입니다. 최초 1회 **전체 구축**만 직접 누르면 됩니다.

| 시각 | 작업 |
|---|---|
| 월 07:30 | 전종목 마스터 갱신 (신규상장 반영) |
| 08:40 | 스윙 스캔 (전일 종가 기준) |
| 09:30 · 11:00 · 14:30 | 단타 스캔 (장중 실시간 — 당일봉·체결강도·실시간 순위) |
| 10:30 · 13:00 | 스윙 스캔 |
| 15:50 | 증분 동기화 — 전종목 일봉 + 후보풀 재선정 + 수급 + 프로필 + DART |
| 16:30 | 중장기 스캔 |
| 16:40 | 스윙 스캔 (종가 확정 · 익일 후보) |
| 09:00~15:30 매 10분, 16:05 | 추적 종목 점검 → 텔레그램 알림 |

- **서버를 꺼뒀다 켜면** 놓친 동기화를 자동으로 보충합니다
- 장중에 받은 **미완성 당일봉은 저장하지 않습니다** (장마감 후 확정봉으로 저장)
- 뉴스·미증시·체결강도는 저장하지 않고 스캔 시점에 실시간 조회합니다

## 점수 체계

```
기초점수 85 = 캔들심리15 + 추세구조20 + 수급거래량20 + 패턴구조15 + 실적재료15
종합점수    = (기초 × 0.5 + 전략점수 × 0.425) × 시장계수(0.5~1.2)
```

시장계수는 후보풀 전체의 MA20 상회비율·ADR·신고가 비율로 산출합니다.
하락장에서는 모든 종목 점수가 절반으로 눌립니다.

## 캔들심리 엔진 (최세일 강의 구조 반영)

- **CLV(종가위치)** 중심 — 패턴 이름보다 매수·매도 힘겨루기 수치가 우선
- **복합캔들** 2·3·5봉 합성 후 동일 로직 재적용 (개별 봉에 안 보이는 신호 포착)
- **거래량 가중** 0.4 ~ 1.5배 — 거래량 없는 신호는 죽임
- **위치 가중** 바닥권/천장권에서 같은 캔들의 의미를 뒤집음

## 매매계획 (v1.1)

추천 카드마다 매수·매도 실행계획이 붙습니다.

**매수 방식 자동 분류**

| 방식 | 조건 | 의미 |
|---|---|---|
| 즉시 매수 | 돌파형: 진입가 −1% ~ +5% / 그 외: 진입가 ±1% | 지금 매수 가능 (돌파형은 +5%까지 추격 허용) |
| 돌파 대기 | 현재가가 진입가 아래 | 진입가 돌파 확인 시 매수 |
| 지정가 대기 | 추격 한도 초과 | 진입가까지 되돌림 시 매수 |
| 관망 | 돌파가까지 +7% 초과 | 너무 멀어서 대기 · 자동추적 제외 |

**매도 규칙 (전 전략 공통)**
- 손절가 이탈 → 전량 손절
- 1차 목표 도달 → 50% 매도 + 손절선을 본전으로 상향
- 2차 목표 도달 → 잔량 전량
- 시간손절: 전략별 기한 내 1차 미달 시 정리

| 전략 | 보유기간 | 시간손절 | 신호 유효 |
|---|---|---|---|
| 미너비니 / 오닐 | 20~60일 | 15/20일 | 5일 |
| 웨인스타인 | 20~80일 | 30일 | 5일 |
| 다르바스 | 3~10일 | 10일 | 3일 |
| 와이코프 | 5~20일 | 15일 | 3일 |
| 한국형 눌림목 | 3~10일 | 7일 | 3일 |
| 세력 매집형 | 5~15일 | 12일 | 5일 |

| ~~PAPER~~ | v5.6.1에서 제거 (모의투자 안 씀) |
| **LIVE** | 실전 주문 — **가상매매 검증 게이트 통과**(최종 트랙 청산 60건·40거래일·재현성 "백테스트와 비슷"·탈락 아님) + 확인 문구 입력 후에만 |

(백테스트: 다음날 시가 매도가 종가 매도보다 건당 +0.2%p 내외, 대조군도 같은 폭 → 실행상 유리하고 추정 오차 없음)

**검증**: DRY 10일 시뮬레이션 — 매수가=신호 다음날 시가 20/20, 매도가=판정 다음날 시가 17/17, 중복 주문 차단, 하루 3종목·비중 한도 준수 ·

## v3.4 — 실전 가상매매 자동 판정

판정 기준은 **처음 실행한 날 확정 저장**되고 결과를 보고 바꾸지 않습니다.

| 점검 | 내용 | 두 달에 가능? |
|---|---|---|
| **재현성** | 실전의 승률(±12%p)·보유기간(±2일)·건당 수익(표본오차 2배 이내)이 백테스트 예상 범위 안인가 | ✅ 구현 오류·시장 변화 감지 |
| 대조군 비교 | 같은 신호일끼리 짝지어 비교 · 모델 수만큼 기준 강화(3개 → t ≥ 2.13, 10개 → 2.58) · 백테스트와 같은 방향 · 상위 2건 쏠림 50% 미만 | ⚠ 대형 차이만 감지 |

판정: 표본 부족(청산 60건·40거래일 미만) · 합격 · 유망(연장) · 보류 · 탈락(확연히 나쁨 또는 4개월간 차이 없음)

**현실적인 한계:** 실데이터 기준 하루 단위 (전략 − 무작위) 차이의 변동성이 커서(표준편차 5.5%p),
건당 +0.4%p 우위를 통계로 확인하려면 약 19년, +1%p는 약 3년, +2%p는 약 9개월이 걸립니다.
두 달의 핵심은 **재현성**과 **대형 사고 감지**이며, 대조군 비교는 대부분 "보류"로 나오는 게 정상입니다.

## 증권앱 자동익절 연동 (v1.6)

매수·매도 주문은 증권앱에서 직접 하고, Scout는 **걸어둘 가격을 알려주고 체결을 따라갑니다.**

```
추천 확인 → 앱에서 매수 → (10분 내) Scout가 잔고에서 감지·자동 등록
→ 주문표 텔레그램 → 앱에 익절·손절 주문 설정
→ 앱에서 1차 체결 → Scout가 감지 → "손절 주문을 본전으로 수정하세요"
→ 앱에서 2차 체결 → Scout 청산 기록 · 실제 성과 집계
```

- **호가 단위 보정**: 모든 가격이 KRX 호가 단위로 맞춰져 앱에 그대로 입력 가능
  (익절가는 한 틱 아래로 — 체결 확률↑, 돌파 매수가·손절 감시가는 한 틱 위로 — 먼저 반응)
- **주문표**: 1차 익절(지정가, 절반) · 2차 익절(지정가, 나머지) · 손절(스탑로스, 전량)
- **매일 08:50 텔레그램**: 보유 종목 전체의 오늘 걸어둘 주문 (일반 지정가 주문은 당일만 유효)
- **KIS 잔고 연동** (설정에 계좌번호 8자리): 장중 10분마다 잔고·당일 체결 조회
  - 새로 산 종목 → 자동 등록 (최근 5일 추천에 있으면 그 계획 적용)
  - 수량 감소 → 실제 체결가로 매도 기록 (하루 여러 번 체결돼도 회차별 체결가 분리)
  - 수량 증가 → 추가매수 · 평단 갱신
  - 처음 연동할 때 이미 갖고 있던 종목은 등록하지 않음
  - 보유 중에 기록을 삭제하면 그 종목은 연동에서 제외
- **잔고·체결 조회만 사용** — 주문 API는 코드에 없습니다

### 앱에 주문 걸 때 확인할 것

1. 지정가 매도로 1차+2차를 **전량 걸어두면 매도가능수량이 0**이 되어, 손절(스탑로스)이 발동해도
   매도가 안 나갈 수 있습니다. 증권사 앱의 조건부 주문에서 **이익실현·손실제한을 한 주문으로 함께**
   거는 기능이 있으면 그걸 쓰세요. 증권사마다 동작이 달라 한 번 확인이 필요합니다.
2. 일반 지정가는 당일만 유효 → 다음 날 다시 걸거나, 유효기간을 지정할 수 있는 조건부 주문 사용
3. 1차 체결 후 **손절 주문을 본전·잔량으로 바꾸는 건 앱에서 직접** 해야 합니다 (Scout가 알림으로 알려줌)

## 내 보유 (v1.5)

직접 산 종목을 기록하면 **실제 평단 기준**으로 손절·목표를 관리하고 텔레그램으로 알려줍니다.

- **추천 카드 → "매수했음 · 기록"**: 실제 체결가·수량 입력. 손절가는 추천의 구조적 손절(박스 하단 등)을 유지하고, 목표가는 같은 R배수로 실제 평단 기준 재계산
- **직접 등록**: 추천에 없던 종목도 등록 가능. 손절가를 비우면 ATR×2(최대 −10%)로 자동 설정, 목표 2R·3R
- **일부 매도 기록** → 손절선이 자동으로 본전으로 올라감
- **알림** (한 번씩만): 손절선 근접(2% 이내) · 손절선 이탈 → 손절 검토 · 1차 도달 → 50% 매도 검토 · 2차 도달 · 보유기한 초과 → 정리 검토

### 매수 수량 계산

설정에 계좌 금액을 넣으면 추천 카드마다 수량이 표시됩니다.

```
수량 = min( 계좌 × 허용손실% ÷ (진입가 − 손절가),  계좌 × 최대비중% ÷ 진입가 )
```

예) 계좌 3,000만 · 허용손실 1.5% · 진입 10,000 · 손절 9,300 → 642주 (641만원, 계좌 21%) · 손절 시 −45만원.
손절폭이 넓은 종목은 자동으로 적게 삽니다 (로스 카메론 1거래 리스크 1~2% 원칙).

## 가상 추적 (v1.1 → v1.5에서 알림 끔)

스캔할 때마다 상위 5종목(관망·전략미매칭 제외)이 자동으로 **추적 중** 탭에 등록되고, 카드에서 수동 추가도 됩니다.

```
대기 ─┬─ 진입가 도달 ──→ 진입 ─┬─ 1차 도달 ──→ 1차도달 ─┬─ 2차 도달 → 종료
      ├─ 유효기간 경과 → 신호소멸 ├─ 손절선 이탈 → 손절      ├─ 본전 이탈 → 본전청산
      └─ 손절선 이탈 ──→ 신호소멸 └─ 기한 경과 ──→ 시간손절  └─ 보유기간 만료 → 정리
```

가상 추적은 **전략 성적 검증용**이라 기본적으로 알림을 보내지 않습니다 (설정에서 켤 수 있음). 텔레그램은 *내 보유* 알림만 옵니다.
청산된 건은 **성과** 탭의 *실현 성과*에 전략별 승률·평균손익으로 집계됩니다.
50% 분할매도를 반영한 실제 계획대로의 수익률입니다.
