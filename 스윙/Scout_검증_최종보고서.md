## 6. 최종 시스템 설계 (Scout v3 — 반영 완료)

| 항목 | 설계 | 근거 |
|---|---|---|
| 대상 | 그날 기준 20일 평균 거래대금 30억 이상 | 상장폐지 위험 사실상 0 |
| 후보 점수 | 과매도(RSI) + 외국인 20일 강도 + 기관 20일 강도 역방향, 동일 가중 백분위 | 전종목·두 기간 일관 |
| 출력 | 하루 **최대 3개 "후보"** + 근거(각 요소 백분위) 투명 표시 | 확실한 수익이 아니라 확률이 조금 나은 후보 |
| 매수 | 다음날 시가 부근 | |
| 매도 | 종가가 9일 EMA 이상이면 매도, 최대 10거래일. 목표가 매일 아침 갱신 | 반등 매매에 가장 잘 맞는 청산 |
| 손절 | 고정 손절 없음. −15%는 재난 대비 참고선 | 좁은 손절은 해로웠음 |
| 수량 | 계좌 리스크 기준 수량 계산 유지, **한 종목에 과도하게 싣지 않기** | 개별 종목 변동이 우위보다 큼 |
| 연기금 | 가장 강한 신호지만 KIS 실시간 API가 제공하지 않아 같은 방향의 **기관**으로 대체 | |

### 실전 운용 권장

1. **후보 3개를 모두 소액으로 나눠 담는 것**이 1개에 집중하는 것보다 통계적으로 유리하다 (10종목 → 30종목으로 갈수록 우위가 뚜렷해짐)
2. 가상 추적·내 보유 기록으로 **실전 성과를 계속 쌓고**, 3개월마다 이 보고서의 수치와 비교한다
3. 시스템이 "확신"을 주는 척하지 않는다. 판단은 사용자가 한다
