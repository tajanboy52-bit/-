📋 TK자동매매 시스템

한국투자증권 Open API로 모의투자 → 실전까지 같은 시스템으로 운용하는 회전형 자동매매입니다. 전종목 3년 실제 자료로 검증한 규칙으로 날마다 사고팔고, 모든 주문 · 체결 · 판단을 기록해 그 기록으로 다시 고도화합니다. 다른 앱 없이 혼자 돌아갑니다.

🗺 시스템 구조도 자료 → 신호 → 주문 → 기록 → 분석 → (검증 뒤) 규칙 개선

처음 한 번
  1. ⚙️ 설정: 모의 앱키 · 시크릿 · 계좌 → 🔌 연결 테스트 · KRX 아이디 · 텔레그램(선택)
  2. 📥 데이터: 처음 전체 수집 (ETF 실제 가격 포함 · 1~2시간 · 이어받기) → ⏱ 분봉 조회 점검
  3. 🧪 백테스트 실행 → 결과 확인 (밤사이 두 칸이 실제 ETF 가격으로 다시 계산됨)
  4. TK_AutoStart_On.bat · 절전 1시간 · 절전 해제 타이머 허용 (시스템 종료 말고 절전)
  5. ⚙️ 자동주문 켜기 → 다음 거래일 08:50부터

  1. 아침 텔레그램 · 장 마감 리포트 확인 — 할 일 없음
  2. 🏠 대시보드 · 📡 실시간에서 상태 확인 · 필요하면 수동 주문
몇 주마다
  1. 🔬 분석 · 고도화 → 📦 분석 패키지 · ⏱ 분봉 zip을 Claude에게 → 고도화 점검
  2. 🔁 모의 성적 판정 확인 → 실전 계좌로 전환 (계좌 설정만 바뀜)
문제가 생기면
  1. ⛔ 정지 · 경고 → 🖥 시스템 로그 확인 · 📦 기록 · 점검 zip을 Claude에게
  2. 주문 결과 불분명 → KIS 앱에서 체결 확인 뒤 정지 해제
