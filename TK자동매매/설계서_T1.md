# 🏦 TK자동매매 시스템 T1.0 설계서 (2026-09-30)

## 1. 목표와 결론
- **목표:** 한국투자증권 Open API로 실시간 자동매매를 문제없이 돌린다. 1,000만 원 **모의계좌로 먼저 수익성을 확인**한 뒤 실전 계좌로 바꾼다. 다른 앱에 의존하지 않는다.
- **결론:** 올린 모든 앱과 보고서를 분석해서, **전종목(상장폐지 포함) 두 기간 검증을 통과한 규칙 4개만** 서로 상관이 낮은 칸으로 나눠 운용한다.
  - v8의 장점(실시간 화면 · 수동 주문 · 매시 리포트 · 결과 분석)은 가져왔다.
  - v8의 약점(보안 구멍 · 검증에서 손해로 나온 급등 추격 · 물타기)은 버렸다.

## 4. 전략 — 4칸 (규칙은 검증된 정의 그대로 · 새로 맞춘 값 없음)
| 칸 | 비중 | 규칙 | 근거 |
|---|---|---|---|
| 🏔 저변동고점 LVH | 40% | ATR14/종가 낮음 · 250일 고점 근접 · 25일 과열 없음 → 상위 3 → 20거래일 보유 · 20자리 | 계좌 +34.0% / +22.4% · 낙폭 −5.8% / −7.6% · 변형 8/8 · 무작위 300번 중 98~100% 앞섬 |
| 🔄 반전·수급 REV | 25% | [(RSI14 과매도 + 5일 하락)/2 + 외국인 20일 순매수 + 연기금 20일 역방향]/3 → 상위 3 → 9EMA 복귀 · 10일 매도 · 30자리(종목당 1/30 — 실제 자료 검증 결과 반영) | 4구간 4/4 · 하락장 +1.79%p · LVH와 상관 +0.15 |
| 🏛 배당·가치 DV | 20% | 코스피200 · 코스닥150 · 흑자 · 배당 · 편입 12개월+ → z(배당)+z(1/PBR) · 업종당 4 · 15종목 · 30위 완충 · 월 교체 | 월별 연 +24.4% vs +11.3% (t 1.2~1.7) |
| 🌙 밤사이 ON | 15% | KODEX 코스닥150 15:20 종가 매수 → 다음날 08:35 매도 | t 3.7 · 비용 0.05% 넘으면 이득 사라짐 |

- **후보풀:** 20일 평균 거래대금 30억+ · 1천~50만 원 · 이력 120일+ · 당일 +20% 미만 · ETF/스팩/리츠/우선주 · 거래정지 · 관리 · 투자경고/위험 · 코넥스 제외
- **체결:** 모든 판단은 장 마감 확정 일봉 → 다음 거래일 08:35 장전 시장가(시가 체결)
- **손절 없음:** 꼬리 위험은 종목당 비중(계좌 1.3~2.5%)과 계좌 안전장치로 관리한다

## 5. 실시간 · 안정성 · 보안 설계
- **하루 일정**
  - 07:40 종목 마스터
  - 08:05 휴장일
  - 08:20 점검
  - 08:35 장전 주문
  - 09:02 미룬 매수(매수가능금액)
  - 장중: 60초 체결 반영 · 웹소켓 체결 통보 즉시 · 1분 계좌 평가 · 매시 텔레그램
  - 15:20 ON · 15:45 대조
  - 15:50 수집 (실패하면 30분마다 22시까지) · 18:15 수급 확정 · 18:40 신호 → 리포트
- **주문 안전**
  - 결과 불분명(네트워크) → 재주문 없이 **정지**
  - 거절은 기록만 한다. 장 시간 거절은 09:02에 한 번 더
  - 1회 주문은 한도의 15%, 하루 매수는 60%까지
  - 같은 신호로 두 번 주문하지 않는다
  - 신호가 전 거래일 것이 아니면 사지 않는다
- **장부**
  - 묶음(lot) 단위로 관리해서 같은 종목을 두 칸이 가져도 섞이지 않는다
  - 매도 체결은 그 주문의 증가분만 반영한다 (우량주 앱의 합산 버그를 되풀이하지 않음)
  - 모든 쓰기는 커밋한다 (우량주 앱의 잠금 버그를 되풀이하지 않음)
- **대조:** 장 마감마다 종목별 KIS 잔고와 앱 장부를 대조한다. 앱이 모르는 보유 종목이 있으면 새 매수를 차단한다
- **계좌 안전장치:** 고점 대비 −15% 또는 하루 −4%(장중 1분 평가 포함)가 되면 새 매수를 자동으로 중지한다(매도는 계속) + 텔레그램
- **데이터 품질:** 그날 종목 수가 최근 5일 중앙값의 90% 미만이면 신호를 보류한다
- **보안 (v8의 문제를 막음)**
  - 127.0.0.1에서만 받는다
  - Host 머리글을 확인한다(DNS 재바인딩 차단)
  - CORS를 열지 않는다
  - **실행할 때마다 새로 만드는 세션 토큰**이 없으면 모든 API가 401
  - 바꾸는 요청은 JSON만 받는다 → 다른 사이트가 몰래 요청하는 것(CSRF)을 차단
  - 비밀 값은 **DPAPI 암호화**로 저장하고 로그 · 오류 · zip에서 자동으로 가린다

## 6. 모의 → 실전 절차 (사전 등록)
1. 백테스트(`백테스트_실행.bat`)
   - 두 기간 모두 플러스
   - 검증 기간 낙폭 −20% 이내
   - 샤프가 KODEX 200보다 높음
2. **모의 60거래일+**
   - 수익 > 0
   - 최대 낙폭 −15% 이내
   - 주문 불분명 0 · 잔고 불일치 0
   - 청산 30건+
   - → 🔁 탭에 실시간으로 표시된다
3. 통과하면 확인 문구 → 실전 모드
   - 자동주문은 꺼진 채로 전환된다
   - 🔌 실전 연결 테스트를 먼저 한다
   - 실전 자동주문을 켤 때 확인 문구를 한 번 더 입력한다
4. 실전 운용 한도는 **30% → 60% → 100%** (20거래일마다) — 모의와 실전의 체결 차이를 작은 돈으로 먼저 확인한다

## 8. 한계 (솔직하게)
- **실제 한국투자증권 서버 · KRX로는 이 작업 환경에서 시험하지 못했다** (외부 접속이 막혀 있음). 모든 호출은 공식 샘플의 규격대로 만들었고 가짜 서버로 시험했다. 첫 실행 때 🔌 연결 테스트 · 📥 수집 · 첫 장전 주문 로그를 꼭 확인할 것

- 모의투자는 체결 · 비용 · 배당이 실제와 다르다 → 실전은 작은 한도부터 시작한다

- LVH만 보면 10일 보유가 20일보다 약함 (단독 +12.8% vs +16.6%) — 합성에서는 남는 현금이 밤사이로 더 돌아 전체가 좋아짐
- 자료가 2022-09부터라 긴 하락장은 검증 못 함 · 밤사이 칸 비중이 커서 밤사이 악재(미국 급락 등) 갭에 노출 — 계좌 안전장치(−15% · 하루 −4%)는 그대로

## 15. ⏱ 1분봉 수집기 (2026-10-01)

- 날짜별 대상은 **그날 알 수 있던 정보로만**: 직전 20일 거래대금 상위 200 (그날 자료 안 씀) · 전날 신호 후보 · 보유 · 거래 · ETF 2 · 그날 급등락(대상 고르기에만 · 검증은 분마다 그때 알 수 있던 것만)
- 이어받기(종목 · 날짜별 완료 표시) · 장 시간 피해서 과거 채우기 · 실전 키가 있으면 시세 조회만 실전 도메인으로
- 다음 단계: 분봉이 몇 달 쌓이면 장중 규칙 후보를 미리 정한 기준(조정/검증 두 기간 · 비용 · 대조군)으로 시험 → 통과한 것만 장중 자동매매로


## 16. 타사 증권사 API 비교로 넣은 기능 (2026-10-01)
키움 REST API · LS · NH · 넥스트레이드 · 미국 Alpaca 등과 비교 → 우리 회전형 구조에 바로 도움 되는 5가지
1. **예약주문 (KIS CTSC0008U · 실전 전용)**: 15:40~다음 날 07:30 접수 → 다음 영업일 장 시작에 KIS가 주문 전송. 신호 계산 뒤 다음 날 팔 것을 예약 → PC가 꺼져도 매도. 아침 예약 조회(CTSC0004R)로 주문번호 연결 · 거부 · 미처리는 09:02 시장가 재전송 · 긴급 정지 때 예약 취소(CTSC0009U) 시도 (예약주문조직번호가 없어 실패하면 KIS 앱에서)
2. **텔레그램 명령**: 설정한 채팅방 · 2분 안 메시지만 · 처음 켤 때 밀린 명령 무시 · 자동주문 켜기는 앱에서만
3. **그림자 운용**: 미리 정한 실험 설정 7개를 같은 규칙 엔진으로 나란히 — '앞으로'(켠 날 뒤 새 자료) 열이 진짜 표본 밖 비교
4. **장전 예상체결 웹소켓 H0STANC0**: 필드 0 종목 · 2 예상가 · 5 전일 대비 % · 체결가 구독과 합쳐 40개 안
5. **주문 안전장치**: 분당 · 하루 주문 수, 같은 묶음 중복, 수동 30초 중복, 큰 금액 실수
- 넣지 않음: 브래킷 · 트레일링 손절(검증상 손절 불리), HTS 조건검색(신호 직접 계산), 신용 주문 · 검토 대기: NXT/SOR · 최유리/IOC · VI · 입출금 내역 · 장중 투자자 추정 (자료가 쌓인 뒤)

## 17. ⏱ 장중 연구실 · 장중 칸 IN (2026-10-01) — 기존 규칙에 "더하기"

**원칙**: 지금까지 만든 규칙(LVH · REV · ON · SW)은 그대로 둔다. 장중 매매는 1분봉으로 검증해서 좋을 때만 함께 쓴다.

### 17.1 연구실 (`tk_intraday.py` · 🔬 분석 탭 카드 · 날마다 신호 계산 → 그림자 운용 다음에 자동)
- 자료: `minute.db`. 대상은 그날 기준으로 미리 정해진 종목만 쓴다(직전 20일 거래대금 상위 · 전날 후보). 그날 급등락으로 고른 종목은 결과로 고른 표본이라 뺀다.
- 분봉이 끝난 뒤 신호를 판단하고, 다음 분 시가에 산다. 미끄러짐은 한쪽 0.05%로 잡는다.
- 수수료와 거래세 0.20%를 반영해 왕복 비용은 약 0.33%다.
- 15:15 시가에 모두 정리한다. 같은 분에 익절과 손절이 함께 닿으면 손절로 친다.
- 대조군: 같은 날 · 같은 시각에 대상 중 무작위 5종목을 같은 익절 · 손절 폭으로 산 결과와 비교한다.
- 앞 절반 · 뒤 절반 두 기간으로 나눠서 본다.
- 미리 정한 규칙 4개(값 고정):

| 규칙 | 신호 | 청산 |
|---|---|---|
| GAPREV 시가 급락 되돌림 | 시가 −3%~−15%, 09:05~10:00에 첫 5분 고가 돌파 | 익절 = 전날 종가 · 손절 = 그때까지 저가 −0.5% |
| ORB 장 초반 돌파 | 09:00~09:29 범위(폭 1~8%) 고가를 09:30~11:00에 돌파 · 거래량 2배 · VWAP 위 | +3% · 범위 저가(최대 −3%) |
| VWAP 되찾기 | 10:00~14:00, 30분 넘게 VWAP 아래 있다가 위로 (전날 대비 −6%~+2%) | +2% · −2% |
| PULL 후보 눌림 | 전날 LVH·REV 후보 상위 20이 전날 종가 −2% 아래로 마감한 분 (시가는 그 위) | +3% · 손절 없음 |

- **판정 기준** (결과를 본 뒤 바꾸지 않음):
  - 거래일 40일 · 거래 60건 이상이고, 기간별로 각 20건 이상
  - 두 기간 모두 비용 뺀 평균이 0보다 큼
  - 두 기간 모두 대조군보다 나음
  - t ≥ 2
  - 모자라면 '자료 부족'으로 둔다.
- 연구실과 실매매는 **같은 신호 함수**를 쓴다. 한 분씩 늘려 가며 판단한 결과와 하루 전체로 판단한 결과가 같은지 시험한다(미래 분봉을 쓰지 않는지 확인).

### 17.2 장중 칸 IN (⚙️ 설정 · **기본 꺼짐**)
- 연구실 '통과' 규칙 중에서 설정에서 고른 것만 쓴다. 미통과 규칙은 켜도 쓰지 않는다.
- 돈: 낮에 노는 돈만 쓴다(아침에 판 밤사이 ETF · KODEX 200 자금).
  - 계산: min(주문 가능 현금, 운용 자금 − LVH·REV·DV 보유) × `intraday_pct`(50%)
  - 이 돈을 `intraday_slots`(5)자리로 나눠 쓴다.
- 웹소켓 체결가로 1분봉을 직접 만든다(늦게 켜졌으면 REST 오늘 분봉으로 앞부분을 채움). 신호가 '방금 끝난 분'에 났을 때만 시장가로 산다. 같은 종목은 하루 1번만 산다.
- 익절 · 손절은 실시간 체결가로 판단한다.
- 15:15에 남은 것을 모두 시장가로 정리한다. 그래서 15:20 밤사이 매수 돈은 건드리지 않는다. 못 팔면 다음 날 장전에 매도한다.
- 주문 안전장치 · 계좌 안전장치 · 새 매수 중지 · 자동주문 정지가 모두 그대로 적용된다.
- 쓰는 순서: 연구실 통과 → 모의에서 켜기 → 실전.

## 18. 📰 DART 공시 (2026-10-04) — 악재 공시 거르기 준비

- **수집** (`tk_dart.py`)
  - OpenDART 공시검색(list.json)으로 받는다. 대상은 주요사항보고(B) · 거래소공시(I) · 발행공시(C)이고, 상장사(유가 · 코스닥)만 남긴다. 저장 위치는 market.db의 `dart` 표다.
  - 거래일 18:05에 오늘 공시를 받고, 과거 250거래일은 하루 호출 한도 안에서 이어받는다. 받은 날은 다시 받지 않는다.
- **분류**
  - 악재: 유상증자 · CB · BW · EB · 감자 · 횡령배임 · 상장폐지 · 관리종목 · 불성실공시 · 회생 · 소송 · 거래정지 · 영업정지 · 감사의견
  - 호재: 자사주취득 · 무상증자 · 공급계약 · 현금배당
- **연구**
  - 신호 후보(LVH · REV 상위 50)를 직전 5거래일 안에 악재 공시가 있었던 종목과 없었던 종목으로 나눠 비교한다.
  - 수익은 다음 날 시가에 사서 5일 뒤 종가까지로 계산한다(비용 전). 결과는 📥 데이터 탭 DART 카드에 나온다.
- **매수 거르기**
  - 설정 `dart_filter`로 켜고 끈다. **기본은 꺼짐**이다.
  - 켜면 직전 5거래일 안에 악재 공시가 있는 LVH · REV 후보는 사지 않고, 이유를 판단 기록에 남긴다.
  - 연구 결과가 꾸준히 나쁠 때만 켠다. 순서는 모의 → 실전이다.
- **내보내기**
  - 📦 공시 CSV에서 기간을 골라 저장할 수 있다.
  - 📦 분석 패키지에도 `dart.csv`가 들어간다.
