# 🏦 TK자동매매 시스템 (T1.1)

**한국투자증권 Open API 자동매매 — 모의투자로 먼저 수익을 확인한 뒤 실전으로.**
다른 앱(Scout · Danta · Bluechip · v8)이 없어도 혼자 돌아갑니다. 자료 수집 → 신호 → 주문 → 체결 · 장부 → 리포트를 모두 이 폴더에서 합니다.
주소 http://127.0.0.1:8086 (이 PC에서만) · 데이터 `%APPDATA%\TKAuto` · 설계 · 근거: **`설계서_T1.md`**

## 처음 설정 (한 번)
1. 파이썬 3.10+ 설치 (python.org · "Add to PATH" 체크)
2. `TK_Run.bat` 더블클릭 → 부품 자동 설치 → 브라우저가 열림
3. **⚙️ 설정**
   - 🟢 **모의투자** 앱키 · 시크릿 · 계좌(8-2) · HTS ID(체결 통보용, 선택) → 🔌 모의 연결 테스트
     (KIS 홈페이지에서 모의투자 신청 → 모의투자용 앱키를 따로 받음. **이 앱 전용 모의계좌**를 권장)
   - **KRX 아이디 · 비밀번호** (data.krx.co.kr 무료 가입) — 전종목 자료 수집에 필요
   - 텔레그램 (선택) — 장 마감 리포트 · 매시 리포트 · 중요 경고
   - 비밀 값은 **윈도우 DPAPI로 암호화**해서 저장됩니다 (이 PC · 이 사용자만 풀 수 있음)
4. **📥 데이터 → 처음 전체 수집** (2022-06 ~ 오늘 · 전종목 + 상장폐지 · 약 1~2시간 · 꺼도 이어받음)
   - **내장 자료 (자동):** 앱에 이미 들어 있음 → 처음 켤 때 자동으로 DB에 — **전종목 일봉 2022-09 ~ 2026-09-22 (278만 줄 · 3,176종목)** · 수급(외국인 · 기관 · 연기금) 2023-09 ~ 2026-09-22 · 월별 구성 종목 · 업종 · 재무 2019-01 ~ 2026-09
     → 내장 자료만으로 바로 백테스트 가능. 처음 전체 수집은 2022-06 ~ 2022-08과 빠진 날만 채우면 됨
   - **TK_STOCK_CHART_DB 백업 (`swing_chart.db`)** 도 `가져오기`에 넣으면 자동으로 들어감
   - **가져오기 폴더 (자동):** `TK자동매매\가져오기`에 Scout 내보내기(`scout_allmarket_연도_*.zip` 일봉 · `scout_allflow_연도_*.zip` 수급) · csv를 넣으면 **10분 안에 자동으로 DB에** (같은 파일은 다시 안 넣음 · 같은 날짜·종목은 새 값으로 덮어써 중복 없음)
   - **매일 자동:** 장 마감 뒤 KRX에서 그날 일봉 · 수급 · 월 자료를 받아 이어서 쌓음 → 자료가 끊기지 않고 계속 누적
5. **🧪 백테스트 → 실행** → 결과(`%APPDATA%\TKAuto\backtest_result.md`)를 Claude에게 보내 점검
6. **⚙️ 설정 → 자동주문 켜기** → 다음 거래일 08:35부터 모의 주문
7. `TK_AutoStart_On.bat` — PC가 켜지면 자동 실행 (절전 모드는 "안 함")

## 모의 ↔ 실전 — 계좌만 바뀌고 시스템은 그대로
- 화면 맨 위 띠의 **[🟢 모의 | 🔴 실전]** 버튼(또는 🔁 탭)으로 전환 → 바뀌는 것은 **계좌 설정(앱키 · 시크릿 · 계좌번호 · 운용 한도)과 그 계좌의 장부**뿐
- 전략 · 칸 비율 · 일정 · 안전장치 · 자동주문 ON/OFF는 그대로 · 실전으로 갈 때 확인 창 한 번
- 계좌별 운용 한도를 따로 정할 수 있음 (비우면 공통 한도) · 실전 처음 단계 한도(30→60→100%)는 선택
- 모의 성적 판정(60거래일 · 수익 · 낙폭 · 사고 0 · 청산 30건)은 **참고로 표시** (전환을 막지 않음)
